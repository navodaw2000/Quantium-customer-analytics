# 📊 Quantium Retail Customer Analytics – Chips Category

This project analyses customer purchasing behaviour for the **Chips category** using transaction and customer data provided by Quantium.
The goal is to identify customer segments, purchasing trends, and commercial insights that will support the client’s strategy for the upcoming category review.

## 🎯 Project Objectives

* Clean and validate customer + transaction data
* Identify inconsistencies, outliers, incorrect product records
* Create derived variables such as:

  * **Pack size**
  * **Brand name**
* Define and analyse metrics such as:

  * Total sales
  * Units sold
  * Sales by customer segment
  * Customer penetration & spend
* Explore **customer segments** based on:

## 🛠 Tools & Technologies Used

* **R Programming**

  * dplyr, ggplot2, readr, tidyr
  * RMarkdown for reporting
* **Excel/CSV** for data review
